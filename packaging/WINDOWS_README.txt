完整社区设施需求预测与动态匹配系统 - Windows版

使用方法
1. 将压缩包完整解压到普通文件夹，不要直接在压缩包预览窗口中运行。
2. 双击 CommunityPredictionSystem.exe。本版本是真正的单文件程序，exe 也可以单独复制到其他 Windows 电脑使用。
3. 首次启动需要解压内置资源，通常需要数秒；程序会等待服务完全就绪后再打开浏览器。
   发布包文件名末尾的12位字符是构建标识。更新时请使用标识不同的新包，不要继续运行下载目录中的旧副本。
4. 默认地址为 http://127.0.0.1:8765；若端口被其他程序占用，系统会自动选择后续可用端口，实际地址会显示在启动窗口中。
5. 关闭程序窗口即可停止服务。重复双击时，如果系统已经运行，将直接打开现有页面。

单界面与嵌入大系统
- 系统默认地址 http://127.0.0.1:8765 已直接改为单界面工作台。
- 兼容入口：http://127.0.0.1:8765/workspace
- 默认跳过初始工程选择页，不显示左侧功能列，但完整保留六项业务功能。
- 可通过 projectId 指定工程，例如：http://127.0.0.1:8765/workspace?projectId=9
- 完整按钮、跳转和 iframe 接入示例见“单界面嵌入接入说明.md”。

数据位置
- 数据库和工程数据保存在 %LOCALAPPDATA%\CommunityPredictionSystem，不再放在程序安装目录。
- 首次启动新版时，如果程序目录下存在旧 data 文件夹且用户数据目录尚未创建，系统会自动迁移一份。
- 更新或重新解压程序不会覆盖用户数据；仍建议在“工程管理”中定期下载系统完整备份。
- 可在工程管理查看实际数据目录，迁移设备请使用工程 ZIP 或系统备份 ZIP。

环境要求
- Windows 10/11 64位。
- 无需安装 Python、Node.js 或数据库。
- Word 报告生成不要求安装 Microsoft Word；打开报告需要可读取 docx 的软件。

常见问题
- Windows 首次运行可能显示 SmartScreen 安全提示。请先核实文件来源；如确认来自本项目，可选择“更多信息”→“仍要运行”。
- 若文件属性中显示“此文件来自其他计算机”，可右键 exe → 属性 → 勾选“解除锁定”后再运行。
- 若日志显示“API 与前端资源均已就绪”但浏览器仍显示资源未加载，请先核对日志中的“前端构建标识”是否与压缩包文件名末尾一致；不一致说明运行了旧副本。
- 杀毒软件可能对未进行商业数字签名的新生成 exe 进行隔离。若程序消失或无法启动，请先查看 Windows 安全中心的保护历史记录。
- 系统会自动避让被占用端口，不需要用户修改配置。
- 启动失败会弹出原因和诊断日志路径。日志默认位于：
  %LOCALAPPDATA%\CommunityPredictionSystem\logs
- 如果浏览器没有自动打开，请按启动窗口显示的地址手动访问。
- 建议将程序放在本机磁盘的普通文件夹中运行，不要放在只读目录、网盘同步目录或压缩包内部。
